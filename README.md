# Mafia Game Master Bot

> Ведущий классической «Мафии» для Telegram-группы — с тайными ролями и действиями без личного чата с ботом.

Бот создаёт лобби, управляет фазами ночи и дня, ведёт тайное голосование и завершает игру по классическим условиям победы. Роли, ночные цели и результаты проверки комиссара отображаются через ephemeral-панели только нужному игроку внутри того же группового чата.

## Быстрый запуск

Нужны Node.js 20+, PostgreSQL 14+ и бот, созданный через [@BotFather](https://t.me/BotFather).

```bash
npm install
cp .env.example .env
# Заполните BOT_TOKEN в .env, затем выполните миграции.
npx prisma migrate deploy
npm run dev
```

Для production-сборки:

```bash
npm run build
npm start
```

После запуска добавьте бота в нужную группу и отправьте `/mafia`.

## Что умеет бот

- 🎭 Лобби с кнопками участия и лимитом от 5 до 20 игроков.
- 🔒 Тайные роли и ночные действия через персональные ephemeral-панели в группе.
- 🌙 Автоматический цикл ночи, обсуждения и тайного голосования.
- 🏁 Финальное раскрытие ролей только после победы одной из сторон.
- ♻️ Восстановление активных игр и дедлайнов после перезапуска.

## Пример игры

```text
/mafia
🎭 Лобби «Мафии» открыто
👥 Игроки: 5/20

Игроки нажимают «✅ Участвовать», организатор — «▶️ Начать игру».
Затем каждый открывает «🔒 Открыть личную панель» прямо в группе.
```
