# Mafia Game Master Bot

> Ведущий городской «Мафии» для Telegram-группы: тайные роли и ночные действия остаются внутри группы в персональных ephemeral-панелях.

Бот ведёт игру на 6–15 участников: в коротких составах нет части спецролей, с девяти игроков Шлюха ходит первой, затем мафия с Доном, Шериф, Доктор и Маньяк; дневная часть состоит из открытых номинаций, голосования и городских развязок ничьей. PostgreSQL — источник состояния, поэтому фазы и дедлайны восстанавливаются после перезапуска.

## Быстрый запуск

Нужны Node.js 20+, PostgreSQL 14+ и бот, созданный через [@BotFather](https://t.me/BotFather).

```bash
npm install
cp .env.example .env
# Заполните BOT_TOKEN и DATABASE_URL, затем примените миграции.
npx prisma migrate deploy
npm run dev
```

Для production-сборки:

```bash
npm run build
npm start
```

Добавьте бота в группу и отправьте `/mafia`.

## Возможности

- 🎭 Лобби и точное распределение ролей для 6–15 игроков.
- 🔒 Роли, ночные цели и проверки — только в личных ephemeral-панелях группы.
- 🌙 Ночь Шлюхи → обычная ночь с мафиозным советом, Шерифом, Доктором и Маньяком.
- 🗳️ Открытые городские номинации, голосование, ограниченный ревот и финальное решение при повторной ничьей.
- ♻️ Восстановление нейтральных control-сообщений и дедлайнов после перезапуска.

## Пример игры

```text
/mafia
🎭 Лобби «Мафии» открыто
👥 Игроки: 9/15

Игроки нажимают «✅ Участвовать», организатор — «▶️ Начать игру».
Затем каждый открывает «🔒 Открыть личную панель» прямо в группе.
```
