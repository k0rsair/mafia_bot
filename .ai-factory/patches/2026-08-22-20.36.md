# Allow city Mafia games from 6 players by omitting extra roles

**Date:** 2026-08-22 20:36
**Files:** src/domain/game/rules.ts, src/application/LobbyService.ts, tests/unit/game/rules.test.ts, docs/game-rules.md, docs/getting-started.md, docs/manual-acceptance-checklist.md, README.md
**Severity:** medium

## Problem

A new game could start only with 9–15 players. Groups of 6–8 could open a lobby but `/startgame` was rejected, even though shorter city tables simply omit some specials.

## Root Cause

`MIN_PLAYERS` and `ROLE_DISTRIBUTIONS` encoded only the full 9–15 city table. `validateLobbySize` and `calculateRoleDistribution` shared that floor, so there was no legal distribution for 6–8. The 9-player row already omitted Doctor; the same “drop extras as the table shrinks” rule was never extended downward.

## Solution

Lowered `MIN_PLAYERS` to 6 and added rows that peel extras off the 9-player set while keeping Don, Sheriff, and four civilians:

- 6: Don, Sheriff, 4 civilians
- 7: plus Maniac
- 8: plus Шлюха
- 9+: unchanged, including regular Mafia from 9 and Doctor from 13

Existing night/win code already skips a missing Шлюха, Maniac, or regular Mafia. Start rejection now uses a player-facing Russian size message. `[FIX:lobby-min-players]` logs accepted and rejected starts with `gameId` and `playerCount` only.

## Prevention

- Keep lobby min/max and `ROLE_DISTRIBUTIONS` in one table; never lower `MIN_PLAYERS` without a row for every size in between.
- Cover the new minimum with both `calculateRoleDistribution` and `assignRoles` tests, and reject `min-1` / `max+1`.
- When a role count is 0, rely on existing skip paths (no living Шлюха, no Maniac actor) rather than special-casing the phase machine.
