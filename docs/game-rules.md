# Правила и UX игры

## Команды организатора

| Команда | Действие |
|---|---|
| `/mafia` | Создать лобби в текущей группе |
| `/startgame` | Начать готовую игру; доступно создателю лобби или администратору |
| `/mafia_status` | Показать фазу и заново опубликовать актуальную управляющую кнопку |
| `/extendroles` | Продлить фазу подтверждения ролей |
| `/cancelgame confirm` | Отменить игру без раскрытия ролей |

Команда `/help` выводит этот краткий список. В личном чате бот объяснит, что игровой процесс доступен только в группе.

## Состав и роли

Игра поддерживает от 5 до 20 участников. Распределение классическое: мафия составляет примерно треть игроков; при 5 игроках есть комиссар, а с 7 игроков добавляется доктор.

| Роль | Ночное действие |
|---|---|
| 🕶️ Мафия | В приватном совете видит выборы других мафий, выбирает и подтверждает свою цель; при равенстве подтверждённых выборов убийства нет |
| 🔍 Комиссар | Проверяет одного другого живого игрока |
| 💉 Доктор | Спасает любого живого игрока, включая себя |
| 🕊️ Мирный житель | Ночью не действует, участвует в обсуждении и голосовании |

Мирные побеждают, когда мафии не осталось. Мафия побеждает, когда её число не меньше числа мирных.

## Ход игры

1. 🎭 **Лобби.** Игроки используют кнопки «Участвовать» и «Выйти»; список виден всем.
2. 🔒 **Подтверждение роли.** Каждому доступна нейтральная кнопка «Открыть личную панель». Роль и подтверждение видны только этому игроку в ephemeral-сообщении. По таймауту организатор может применить `/extendroles` или отменить игру.
3. 🌙 **Ночь.** Группа видит только нейтральную кнопку. У каждой мафии открывается приватный «🕶️ Совет мафии»: там видны только мафиям черновики и подтверждения всех мафиози. Сначала можно выбрать цель, затем подтвердить голос; убийство учитывает только подтверждённые голоса. Изменение своей цели снова делает голос черновиком. Доктор может изменить выбор до дедлайна; комиссар получает результат первой проверки и больше не выбирает цель этой ночью.
4. ☀️ **Рассвет и обсуждение.** В группе публикуется только факт выбытия либо его отсутствия.
5. 🗳️ **Голосование.** Все живые игроки видят кнопки кандидатов и «Пропустить». Бот показывает только общий прогресс `Голоса: N/M`; кто и за кого голосовал, не публикуется.
6. 🏁 **Финал.** После условия победы бот объявляет сторону-победителя и единственный раз раскрывает все роли.

## Приватность и устойчивость

- Callback payload не содержит роль; он проверяется по `gameId`, версии фазы, чату и живому игроку.
- У каждого игрока одна актуальная ночная цель и один актуальный голос; повторное нажатие заменяет выбор, а не создаёт второй. Для мафии цель сначала является черновиком и учитывается только после личного подтверждения.
- При пропаже ephemeral-панели игрок снова нажимает кнопку в нейтральном групповом control-сообщении. Личный чат с ботом не нужен.
- После рестарта бот восстанавливает игру из PostgreSQL и заново публикует control-сообщение. Сами ephemeral-сообщения не восстанавливаются, потому что они краткоживущие.
- В production-диагностике допустимы только `gameId`, `chatId`, `phase`, числа и статусы. Запрещены токены, роли, ночные цели, содержание скрытых панелей и соответствия «игрок → кандидат».
