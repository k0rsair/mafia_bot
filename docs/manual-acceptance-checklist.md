# Ручная приёмка

Проводите сценарий в закрытой тестовой группе с 5–7 тестовыми аккаунтами. Не используйте production-токен и реальных игроков.

## Перед началом

- [ ] `npm run check` завершился успешно.
- [ ] Для тестовой PostgreSQL-базы применена миграция `npx prisma migrate deploy`.
- [ ] В `.env` указан тестовый токен, `LOG_LEVEL=debug`.
- [ ] Бот добавлен в тестовую группу, может писать сообщения и показывать inline-кнопки.
- [ ] Клиенты участников поддерживают Bot API 10.2 ephemeral-панели.

## Основной прогон

- [ ] Отправить `/mafia`; отображается лобби с нумерованным списком и эмодзи.
- [ ] Войти 5–7 разными аккаунтами, выйти одним и снова войти; счётчик не превышает 20.
- [ ] Непривилегированный игрок не может начать или отменить игру.
- [ ] Организатор запускает игру; групповое сообщение не раскрывает ни одной роли.
- [ ] Каждый игрок открывает «🔒 Открыть личную панель» и видит только собственную роль.
- [ ] Повторно открыть панель тем же игроком; роль снова доступна только ему.
- [ ] После подтверждений группа получает ночное control-сообщение.
- [ ] Мафия, комиссар и доктор совершают действия; гражданин видит отсутствие действия.
- [ ] При двух мафиях каждая видит в своей ephemeral-панели только выборы мафии с именем выбравшего, целью и статусом `⏳`/`✅`; мирный, доктор и комиссар этих данных не получают.
- [ ] Мафия выбирает цель как черновик, затем подтверждает её; неподтверждённая цель не влияет на исход ночи.
- [ ] Изменить цель мафии после подтверждения: статус снова `⏳`, пока мафия не подтвердит новый выбор.
- [ ] Доктор выбирает спасение один раз; повторная цель отклоняется и не меняет уже выбранного игрока.
- [ ] Комиссар выполняет одну проверку; повторная кнопка показывает, что проверка этой ночью уже завершена.
- [ ] Когда все живые мафии подтвердили цели, доктор выбрал спасение, а комиссар сделал проверку, рассвет начинается сразу, не дожидаясь `NIGHT_DURATION_SECONDS`.
- [ ] Оставить хотя бы одно обязательное действие незавершённым (в том числе черновик мафии `⏳`): ночь продолжается до дедлайна.
- [ ] На рассвете группа не узнаёт ночные цели, спасение или проверку комиссара.
- [ ] Во время дневного обсуждения автор лобби или администратор выполняет `/startvote`: голосование и его кнопки появляются сразу, с новым дедлайном голосования.
- [ ] `/startvote` вне дневного обсуждения или от обычного игрока отклоняется без смены фазы.
- [ ] Во время голосования виден только прогресс `N/M`; голосовавший и кандидат не раскрываются.
- [ ] Сменить голос, проверить ничью и «Пропустить»; при закрытии никто не выбывает в этих случаях.
- [ ] Довести игру до победы мирных и отдельным прогоном — до победы мафии; роли раскрываются только в сообщении `🏁`.

## Сбои и границы

- [ ] Не подтверждать роль до таймаута; `/extendroles` публикует свежую нейтральную кнопку, `/cancelgame confirm` не раскрывает роли.
- [ ] Закрыть или не доставить ephemeral-панель; игрок вновь открывает её из group control-сообщения.
- [ ] Нажать старую кнопку после смены фазы; бот отвечает, что она устарела, без изменения игры.
- [ ] Нажать игровую кнопку из другого чата или от исключённого игрока; действие отклоняется.
- [ ] Перезапустить процесс в каждой активной фазе; после запуска появляется новое control-сообщение, а дедлайны продолжают обрабатываться.
- [ ] Быстро нажать callback более восьми раз за 10 секунд; применяется rate limit и кнопка получает ответ.
- [ ] Проверить логи: есть `gameId`, `chatId`, `phase` и счётчики, но нет токена, роли, цели или текста скрытой панели.
