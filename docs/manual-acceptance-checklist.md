# Ручная приёмка

Проводите сценарии в закрытой тестовой группе с 9–15 тестовыми аккаунтами либо с `/testgame`. Не используйте production-токен и реальных игроков.

## Перед началом

- [ ] `npm run lint`, `npm run typecheck`, `npm test`, `npm run build`, `npx prisma validate` и `npx prisma generate` завершились успешно.
- [ ] Для изолированной тестовой PostgreSQL-базы применена миграция `npx prisma migrate deploy`.
- [ ] В `.env` установлен тестовый токен и `LOG_LEVEL=debug`.
- [ ] Бот добавлен в тестовую группу, может писать сообщения и показывать inline-кнопки.
- [ ] Клиенты участников поддерживают Bot API 10.2 ephemeral-панели.
- [ ] Для виртуального прогона `TEST_GAME_ENABLED=true` включён только с тестовым токеном.

## Лобби и роли

- [ ] `/mafia` открывает лобби; новая игра не стартует с 8 или 16 игроками и стартует с 9–15.
- [ ] В лобби из 9 игроков есть 1 Мафия, 1 Дон, 4 Мирных, Шлюха, Шериф и Маньяк; Доктор появляется только с 13 игроков.
- [ ] Непривилегированный игрок не может начать или отменить игру.
- [ ] После старта нейтральное групповое сообщение не раскрывает роли.
- [ ] Каждый игрок открывает личную панель и видит только свою роль; Шериф нигде не называется «Комиссар».
- [ ] `/roles_pending` приходит только организатору или администратору и показывает лишь список неподтвердивших роль.
- [ ] `/restore_panel` повторно открывает актуальную личную панель в той же группе, не отправляя её в личный чат.

## Ночь

- [ ] После подтверждения ролей первой открывается только личная панель живой Шлюхи. Если Шлюхи нет в живых, бот сразу переходит к обычной ночи.
- [ ] Шлюха не может выбрать себя или того же клиента второй раз подряд; её посещение Мафиози или Дона блокирует выстрел мафии.
- [ ] Посещённые Шериф, Доктор, Дон и Маньяк получают статус блокировки личного действия, не останавливая ночь.
- [ ] Мафия и Дон видят приватный совет, выбирают и подтверждают цель. Неподтверждённый черновик не влияет на исход; смена цели снова требует подтверждения.
- [ ] Дон дополнительно проверяет одного другого живого игрока на Шерифа; результат не видит группа.
- [ ] Шериф видит Мафию и Дона как мафию, но не Маньяка; результат не видит группа.
- [ ] Доктор не лечит ту же цель две ночи подряд, лечит себя не больше одного раза за игру и не спасает от Маньяка.
- [ ] Маньяк либо выбирает другого живого игрока, либо нажимает явный пропуск; повторное нажатие не создаёт второе действие.
- [ ] Если мафия убивает Шлюху, погибает и клиент; лечение Шлюхи спасает обоих, лечение клиента оставляет в живых только клиента. При смерти Маньяка его выбытие объявляется публично.
- [ ] Когда все требуемые или заблокированные действия завершены, рассвет начинается сразу; незавершённая ночь корректно закрывается дедлайном.
- [ ] Рассвет не раскрывает ночные цели, лечение, проверки или Шлюху как источник алиби.

## Городской день

- [ ] `/startvote` от организатора или администратора во время обсуждения открывает публичные номинации; от обычного игрока или вне обсуждения команда не меняет фазу.
- [ ] Каждый живой игрок номинирует только одного из сохранённого состава участников. `/closenominations` закрывает раунд только для организатора или администратора.
- [ ] Ноль или один номинант не приводят к казни и запускают ночь.
- [ ] Два и более номинанта открывают основное публичное голосование только за номинированных кандидатов без «Пропустить».
- [ ] В группе видны прогресс и пары «кто за кого»; повторное нажатие того же игрока обновляет только его голос.
- [ ] Первая ничья открывает ровно 30 секунд обсуждения и ограниченный ревот только среди связанных кандидатов.
- [ ] Вторая ничья открывает публичный выбор «Казнить всех» / «Оставить всех». При казни бот обрабатывает всех связанных кандидатов.
- [ ] Алиби Шлюхи оставляет защищённого кандидата в живых, сообщает об алиби без указания его источника и истекает после дневного исхода.

## Победа, восстановление и безопасность

- [ ] Отдельно проверить победу мирных, победу мафии после ухода Маньяка и победу Маньяка только в паре с Мирным жителем. Полное раскрытие ролей происходит только в финальном сообщении.
- [ ] Нажать старую кнопку после смены фазы или раунда: бот сообщает об устаревании и не меняет игру.
- [ ] Нажать игровую кнопку из другого чата или от выбывшего игрока: действие отклоняется.
- [ ] Перезапустить процесс в `NIGHT_PROSTITUTE`, `NIGHT`, `DAY_NOMINATION`, `DAY_VOTE`, `DAY_TIE_DISCUSSION`, `DAY_REVOTE` и `DAY_FINAL_DECISION`: после запуска появляется правильный нейтральный control, а дедлайны продолжаются.
- [ ] Включить `TEST_GAME_ENABLED=true` в отдельной группе: `/testgame` создаёт одного реального и восемь виртуальных игроков; виртуальные роли и голоса идут автоматически, действие организатора остаётся ручным.
- [ ] Проверить логи: допустимы `gameId`, `chatId`, фаза, версия, статусы и счётчики; отсутствуют токен, роль, цель, проверка, текст личной панели и соответствие игрока кандидату.
